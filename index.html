Gemensam testtavla • 2027–2029 • Supabase

1. Anslut testprojektet

Den här testversionen använder din Supabase-databas. Projektadressen och den publika nyckeln sparas endast i den här webbläsaren. Använd aldrig en secret/service_role-nyckel.

Du hittar nyckeln i Supabase → Project Settings → API Keys → Publishable key.

2. Logga in

Logga in med användaren du skapade under Authentication → Users, inte med ditt GitHub-konto.

Har du använt Apples ”Dölj min e-postadress”? Ange den adress som användaren registrerades med i Supabase.
